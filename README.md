Your assignment is to build a React Firebase Authentication Application using Vite. In this project, you are required to implement Firebase Authentication with features such as user registration, login, forgot password, and logout. You should also use React Router DOM for navigation and protect the Dashboard page so that it is accessible only to authenticated users.



Make sure to follow a proper folder structure, create reusable components where appropriate, apply form validations, and design a clean and user-friendly interface using any styling framework of your choice.



The purpose of this assignment is to help you gain hands-on experience with Firebase Authentication and strengthen your understanding of React fundamentals and routing.
